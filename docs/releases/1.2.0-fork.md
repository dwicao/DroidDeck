# DroidDeck 1.2.0 — Startup failure explanations + GOG SDK cloud saves

This release ports three upstream fixes and teaches Launch Doctor a fourth rule.

- **Steam startup failures, explained.** The session log is now classified at
  session end: Steam exiting with status 132 (illegal instruction) gets a CPU
  explanation plus an x86-64 client hint on ARM64 sessions, and gamescope
  finding no Vulkan device gets a graphics-driver explanation instead of the
  generic stopped message (upstream #1380).
- **Turnip guard.** Automatic display-driver selection leaves non-Adreno GPUs
  on the system driver instead of picking an incompatible Turnip build; Quest,
  external overrides, and manual selections keep priority.
- **GOG Galaxy SDK cloud saves.** Games with `cloudStorage` enabled but an
  empty `locations` list are Galaxy SDK IStorage under `__default`, not "no
  cloud" (upstream #970). A cached "no cloud" is retried after a day, downloads
  peel GOG's gzip, and ISO-8601 cloud timestamps are honored.
- **Launch Doctor: missing Windows components.** A game dying with
  `import_dll ... not found` + `status c0000135` (e.g. DiRT 3's OpenAL32.dll)
  offers fix-and-run: the providing component (oalinst/xact/d3dx9) is
  installed, enabled for the game, and the game retried.
- **Old-kernel compat.** The fast proot path emulates `statx` on kernels older
  than 4.11 (upstream #947).

Deferred with reasons in `docs/upstream-triage.md`: session startup/teardown
locking (#671), target API 36 (#564), 16 KB ELF alignment (#881), X11 focus
after taps (#1461).

### Install

- versionName `1.2.0`, versionCode `42`. It installs over any previous fork
  release and keeps app data.
- The APK is signed with the public AOSP test key. Android may show a Play Protect warning.
- Requires Android 9 or newer. A supported Adreno device is still required for the Steam session.

The APK and its SHA-256 are in the release assets.
