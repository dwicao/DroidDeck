# DroidDeck 1.0.0 — Universal compatibility and stability

The first stable fork release: default storage on any volume with USB/SD/SSD
detection, proven per-game environment defaults, safer graphics defaults, an
idle-friendly Steam home, and working Steam file dialogs — on top of the latest
upstream sync.

- **Built-in per-game environment defaults.** `droiddeck-game-env` ships proven
  defaults keyed by app id, applied before the user's own shared and per-game
  settings (user settings always win). First entry: **NARUTO SHIPPUDEN: Ultimate
  Ninja STORM 4 (349040)** gets `dxvk.maxFrameRate = 30` and
  `DXVK_GPLASYNCCACHE = 1` — a locked 30 FPS base for 2x frame generation with
  async pipeline compilation instead of hitches.
- **Safer graphics defaults.** `VKD3D_FEATURE_LEVEL` now defaults to `12_1`
  instead of `12_2`: vkd3d-proton disables mesh shaders on Adreno anyway, and
  advertising `12_2` crashes Unreal Engine 5 games while creating pipelines
  (RoboCop: Rogue City, #1410).
- **Idle-friendly Steam home.** The floating capsule fan plays its float once on
  appearance and then holds still instead of recomposing every frame forever
  (~2,400 frames per 10 s idle, #1499).
- **Working Browse buttons.** Backported upstream fixes so every Browse button
  on the ARM64 Steam client (Add a Non-Steam Game, shortcut target, library
  folder) opens a file chooser, keeps spaces in the chosen path, and cancels
  cleanly (#1433).
- **USB storage detection.** Volumes without a UUID are kept, unmounted volumes
  are kept, and `/proc/mounts` is used as a fallback, so USB OTG drives appear
  as store install targets even when Android exposes no volume for them (#1478).
- **Non-breaking upstream batch.** Ported with original authorship: GOG cloud
  saves at the location root with old-layout migration (#1177/#1178), Steam
  client CDN probing and resume handover, Xbox sign-in diagnostics and loopback
  fallback, Ubisoft-via-Connect launch path, shared games between arm64 and
  x86-64 Steam clients, experimental external-display output, per-component
  repository sources, update-channel and installer-session guards, launcher
  busy-state handling, runtime data preservation, and the HTTP proxy option.
  See `docs/upstream-triage.md` for the full list.

### Install

- versionName `1.0.0`, versionCode `40`. It installs over the fork's 0.6.13 (versionCode `38`) and
  keeps app data.
- The APK is signed with the public AOSP test key. Android may show a Play Protect warning.
- Requires Android 9 or newer. A supported Adreno device is still required for the Steam session.

The APK and its SHA-256 are in the release assets.
