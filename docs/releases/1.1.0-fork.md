# DroidDeck 1.1.0 — Launch Doctor

Failed sessions now heal themselves. When a session ends abnormally, the log
tail is matched against known failure signatures and the ended screen offers a
one-tap **fix-and-run** next to the usual retry:

- **UE5 mesh-shader crashes** (Turnip + `VKD3D_FEATURE_LEVEL 12_2`, e.g. RoboCop:
  Rogue City) pin the game to `VKD3D_FEATURE_LEVEL 12_1` via a new generic
  per-game env setter (`GameEnvironmentStore.setGameEnv`).
- **Failed Steam client downloads** (transient network error) and **failed Steam
  client setup** re-run on retry; nothing is changed.
- **Loop guard.** A fix applied twice for the same game without the session
  recovering stops being offered — the plain retry button stays available.

Every diagnosis is appended to `launch-doctor.log` as one JSON line, the start
of the failure knowledge base. Failures without a safe programmatic fix (FEX,
seccomp, disk, prefix) stay on the hint-and-retry path by design.

### Install

- versionName `1.1.0`, versionCode `41`. It installs over any previous fork
  release and keeps app data.
- The APK is signed with the public AOSP test key. Android may show a Play Protect warning.
- Requires Android 9 or newer. A supported Adreno device is still required for the Steam session.

The APK and its SHA-256 are in the release assets.
