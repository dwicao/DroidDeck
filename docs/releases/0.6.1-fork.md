# DroidDeck 0.6.1 — Move Steam games between libraries

Steam games can now be moved to another folder without breaking Steam's detection or the launcher's
game list.

### Move a game

- **Setup > Storage > Games** has a new **Move** action next to each Steam game. Targets are internal
  storage, the current SD card library, any folder configured under **Games folder**, or any other
  writable folder through **Choose a folder…**.
- The game's files, Proton prefix, shader cache, workshop content, pending downloads, and manifest
  move together. The manifest goes last, so an interrupted copy does not leave Steam pointing at
  files that are not there yet.
- The destination is registered as a Steam library for the right client: arm64 games are registered
  for the arm64 Steam client and x86-64 games for the x86-64 client. A physical folder belongs to
  one client at a time, and the move refuses to cross them.
- `Games folder` entries in AddedGames are validated as arm64 libraries, including folders that do
  not have a game installed yet.
- Moves are refused when the destination is the current library, inside an existing library, or
  already contains the game or its prefix. A move also needs enough free space plus a small margin,
  and the folder must be writable.
- If any step fails, files that were already copied are put back. After a successful move, stale
  copies of the prefix and shader cache in the old library root are removed when the authoritative
  copy in the private library data is at least as large.
- The session cannot start, and storage cleanup, uninstall, and agent launches are blocked while a
  move is running. The progress dialog keeps the screen on.

### Before you move

- Stop the Steam session first. The move runs in the app, not in Steam, and is not resumable: keep
  DroidDeck open and do not unplug the storage until it finishes. If Android kills the app mid-move,
  some files can be left in the destination.
- Only installed Steam library games are moved. Store installs, Epic games, and shortcuts keep their
  existing storage handling.

### Also in this build

- The fork's default-storage picker, panel pacing and GPU clock pin, game-kit export/import, and
  x86 Linux runtime handling are unchanged.

### Install

- versionName `0.6.1`, versionCode `26`. It installs over the fork's 0.6.0 (versionCode `25`) and
  keeps app data.
- The APK is signed with the public AOSP test key. Android may show a Play Protect warning.
- Requires Android 9 or newer. A supported Adreno device is still required for the Steam session.

The APK and its SHA-256 are in the release assets.
