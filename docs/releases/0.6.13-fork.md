# DroidDeck 0.6.13 — Stable base FPS for frame generation

- **Built-in per-game environment defaults.** `droiddeck-game-env` now ships proven defaults keyed by app id, applied before the user's own shared and per-game settings (user settings always win). First entry: **NARUTO SHIPPUDEN: Ultimate Ninja STORM 4 (349040)** gets `dxvk.maxFrameRate = 30` and `DXVK_GPLASYNCCACHE = 1` — a locked 30 FPS base (the textbook base for 2x frame generation on a 60 Hz display) with async pipeline compilation, so first-time effects hitch for a frame instead of dropping one. A per-game `dxvkConfig` or env override still replaces the built-in values.
- Covered by `test_builtin_game_defaults_apply_and_user_settings_win`.

### Install

- versionName `0.6.13`, versionCode `38`. It installs over the fork's 0.6.12 (versionCode `37`) and
  keeps app data.
- The APK is signed with the public AOSP test key. Android may show a Play Protect warning.
- Requires Android 9 or newer. A supported Adreno device is still required for the Steam session.

The APK and its SHA-256 are in the release assets.
