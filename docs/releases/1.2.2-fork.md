# DroidDeck 1.2.2 — Name the GPU ceiling drop

Small follow-up to 1.2.1: when a session ends cleanly but `perf.csv` shows
the platform lowered the GPU ceiling while the clock was pinned, the ended
screen now says so instead of finishing silently. The advice follows the
active Game Mode (Standard → Game Booster Performance; Performance →
cooling and sustained-load limits). The `ceilingDrop` parser is unit-tested,
and the README troubleshooting section documents the Shizuku-level thermal
override path for advanced users.

### Install

- versionName `1.2.2`, versionCode `44`. It installs over any previous fork
  release and keeps app data.
- The APK is signed with the public AOSP test key. Android may show a Play Protect warning.
- Requires Android 9 or newer. A supported Adreno device is still required for the Steam session.

The APK and its SHA-256 are in the release assets.
