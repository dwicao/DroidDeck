# DroidDeck 0.6.12 — Safer moves: prefix migration, verify, journal, cancel

- **Install into Steam now migrates the Proton prefix (and shader cache) onto the Steam app id** when Steam has none yet, so saves and settings survive adoption instead of starting over. Leftovers that already exist are left untouched.
- **Every copied file is verified**: the bytes on disk must match what was read, otherwise the copy fails loudly and the source is kept.
- **Interrupted moves are journaled.** If the app dies mid-move, Storage reports it with the game name and offers a one-tap discard of the partial copy — finished files are never touched.
- **Moves can be cancelled** from the progress dialog. Already-moved Steam files are put back; added-game partial copies are removed.

### Install

- versionName `0.6.12`, versionCode `37`. It installs over the fork's 0.6.11 (versionCode `36`) and
  keeps app data.
- The APK is signed with the public AOSP test key. Android may show a Play Protect warning.
- Requires Android 9 or newer. A supported Adreno device is still required for the Steam session.

The APK and its SHA-256 are in the release assets.
