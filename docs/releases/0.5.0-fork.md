# DroidDeck 0.5.0 — Blazing Fast Performance

This release merges upstream DroidDeck 0.5.0 into the fork and keeps its thermal and pacing work.

### Fork features kept

- **30 FPS base and 60 FPS with LSFG 2x** on NSUNS4, with the session pacing changes and the thermal guard from 0.4.11.
- **GPU pin and throttle watch**: the GPU stays at its top state while the platform allows it, and the report records any thermal release.
- **Start without Steam**, the per-game environment editor, game switch handling, and Valve/DroidDeck FEX tool selection.
- **Device diagnostics and session reports** with the thermal, GPU, and pacing blocks from the fork.

### Upstream 0.5.0

- SteamVR on Meta Quest 3/3S and experimental Quest 2 support.
- XR glasses support for VITURE, RayNeo, and XREAL, including head-tracked virtual screens.
- Cardboard VR mode, the optional x86-64 Steam client, Linux games through FEX, and Xbox/Game Pass launching.
- The Epic Games Launcher for Linux, store improvements, artwork editing, GPU driver modes, storage cleanup, and the boot movie.
- The upstream frame-pacing, controller, and compatibility fixes listed in the 0.5.0 release notes.

### Install

- versionName `0.5.0`, versionCode `21`. It installs over 0.4.11 (versionCode `20`) and keeps app data.
- The APK is signed with the public AOSP test key. Android may show a Play Protect warning; release-key signing was not available for this build.
- Requires Android 12 or newer. A 64-bit Adreno device is still required for the Steam session.

The APK and its SHA-256 are in the release assets.
