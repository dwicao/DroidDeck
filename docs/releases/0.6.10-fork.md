# DroidDeck 0.6.10 — Moves never silently drop files

Fixes a data-safety hole in every move and copy: a folder the app momentarily cannot list
(common on flaky USB storage) used to be skipped without a word and reported as success, after
which the source was deleted. The copy now retries the listing once, then aborts loudly instead —
nothing is deleted, the partial destination is removed, and the move can simply be retried.

- Applies to Steam game moves, added-game moves and adoptions, and file-manager copies.
- If a previous move reported success but the game is smaller than it should be, move it again
  with this build, or use Install into Steam and let Steam verify and repair the files.

### Install

- versionName `0.6.10`, versionCode `35`. It installs over the fork's 0.6.9 (versionCode `34`) and
  keeps app data.
- The APK is signed with the public AOSP test key. Android may show a Play Protect warning.
- Requires Android 9 or newer. A supported Adreno device is still required for the Steam session.

The APK and its SHA-256 are in the release assets.
