# DroidDeck 0.6.11 — Pick the Steam game for added folders

`Install into Steam` no longer needs an exact match: it lists every Steam game whose install
folder is missing, so any added folder can be adopted into the entry it belongs to. Rows whose
app id has no manifest at all explain the way forward instead of going silent — if the game is
owned on Steam, start a Steam session once to import it, and the entry appears for adoption.

### Install

- versionName `0.6.11`, versionCode `36`. It installs over the fork's 0.6.10 (versionCode `35`) and
  keeps app data.
- The APK is signed with the public AOSP test key. Android may show a Play Protect warning.
- Requires Android 9 or newer. A supported Adreno device is still required for the Steam session.

The APK and its SHA-256 are in the release assets.
