# DroidDeck 0.6.7 — Move added games too

`Setup > Storage` now lists games added with `Games > Add a game` with their full folder size,
next to the Steam games. Each has a working **Move** button: the whole folder moves to internal
storage, the SD card, a games folder, or any picked folder, and every per-folder record moves
with it — the picked exe, the stored app id and name, the game-folder bind (same guest path, so
the session still finds it), the library entry, and the Steam shortcut. Proton prefixes are
keyed by game, not by path, so they keep working untouched.

- Session starts, uninstalls, agent launches, and storage cleanup stay blocked while a move runs,
  and the progress dialog keeps the screen on, same as Steam game moves.
- A failed copy deletes the partial destination so the move can be retried.

### Before you move

- Stop the Steam session first. The move runs in the app, not in Steam, and is not resumable: keep
  DroidDeck open and do not unplug the storage until it finishes.

### Install

- versionName `0.6.7`, versionCode `32`. It installs over the fork's 0.6.6 (versionCode `31`) and
  keeps app data.
- The APK is signed with the public AOSP test key. Android may show a Play Protect warning.
- Requires Android 9 or newer. A supported Adreno device is still required for the Steam session.

The APK and its SHA-256 are in the release assets.
