# DroidDeck 0.6.8 — Added games become Steam games

Fixes moved games still showing Install in Steam: when an added game's folder identifies a Steam
app whose manifest has no installed files, `Setup > Storage` now offers **Install into Steam**
next to **Move**. The folder installs as that library's `steamapps/common/<installDir>`, the
added-game records are retired, and Steam detects the game on its next start — the button says
Play, with the full size counted as a Steam install.

Also fixes moved games leaving a dead shortcut behind: the never-running live sync is replaced
with an immediate library republish, and the session-start script rewrites each shortcut's exe
and start dir by app id, so moved games keep launching from Steam.

### Before you move

- Stop the Steam session first. The move runs in the app, not in Steam, and is not resumable: keep
  DroidDeck open and do not unplug the storage until it finishes.

### Install

- versionName `0.6.8`, versionCode `33`. It installs over the fork's 0.6.7 (versionCode `32`) and
  keeps app data.
- The APK is signed with the public AOSP test key. Android may show a Play Protect warning.
- Requires Android 9 or newer. A supported Adreno device is still required for the Steam session.

The APK and its SHA-256 are in the release assets.
