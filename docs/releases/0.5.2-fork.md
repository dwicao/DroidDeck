# DroidDeck 0.5.2 — Folder-based default storage

This release fixes default storage selection for USB SSDs and other drives that Android does not
report as removable external storage.

### What changed

- **Setup > Storage > Default storage** now offers **Choose folder…**. Pick any writable folder on
  internal storage, an SD card, or a USB drive; DroidDeck creates a `Games` folder inside it and uses
  that for new store installs and the Epic Games Launcher.
- The external storage option is no longer disabled when no app-specific external directory is
  detected. It opens the folder picker instead.
- Non-primary app-specific external directories are now offered even when Android reports their
  volume as non-removable, which is common for USB SSDs connected through a hub.
- If a chosen folder is disconnected, new installs show the normal target prompt instead of silently
  falling back to internal storage. The Epic Games Launcher keeps its existing install folder until
  the drive is available again.
- Games that are already installed are not moved. Steam libraries keep their own **Game storage**
  setting.

### Install

- versionName `0.5.2`, versionCode `23`. It installs over 0.5.1 (versionCode `22`) and keeps app data.
- The APK is signed with the public AOSP test key. Android may show a Play Protect warning;
  release-key signing was not available for this build.
- Requires Android 9 or newer. A supported Adreno device is still required for the Steam session.

The APK and its SHA-256 are in the release assets.
