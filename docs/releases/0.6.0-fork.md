# DroidDeck 0.6.0 — Rebased on upstream 0.6.0

Upstream rewrote `main` after the last merge, which made GitHub show the old upstream history as
thousands of fork-only commits. This build ports the fork's changes onto the current upstream
`main` instead of merging the old history again. The branch is now one commit ahead of upstream.

### Fork changes kept

- **Setup > Storage > Default storage** still chooses internal storage, external storage, any
  writable folder via **Choose folder…**, or asks every time. New store installs and the Epic Games
  Launcher use that choice; existing games and Steam libraries stay where they are.
- The fork's panel pacing, adaptive display pacing, GPU clock pin and thermal guard, per-game launch
  log, game-kit export/import, and x86 Linux runtime handling remain in place.

### Upstream 0.6.0

This build includes everything in upstream 0.6.0, including the Xbox and PC Game Pass store,
itch.io, the redesigned store pages, touchscreen gestures, Remote Play video, boot movies, the
performance HUD frame-time graph, the Gradient theme, SteamVR controller types, Rokid glasses
support, suspend page-out, and the new game logos. See the
[upstream 0.6.0 notes](https://github.com/Droid-Deck/DroidDeck/blob/main/docs/releases/0.6.0.md)
for the complete list.

### Install

- versionName `0.6.0`, versionCode `25`. It installs over the fork's 0.5.3 (versionCode `24`) and
  keeps app data.
- The APK is signed with the public AOSP test key. Android may show a Play Protect warning.
- Requires Android 9 or newer. A supported Adreno device is still required for the Steam session.

The APK and its SHA-256 are in the release assets.
