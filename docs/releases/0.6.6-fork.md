# DroidDeck 0.6.6 — Add games straight from USB SSDs

`Games > Add a game` now lists external SSDs and other removable drives next to internal
storage, so a game folder on a USB drive can be picked directly instead of only browsing
internal storage. Drives that Android does not back with an app folder are included as long
as DroidDeck can read them (grant “All files access” when asked).

### Install

- versionName `0.6.6`, versionCode `31`. It installs over the fork's 0.6.5 (versionCode `30`) and
  keeps app data.
- The APK is signed with the public AOSP test key. Android may show a Play Protect warning.
- Requires Android 9 or newer. A supported Adreno device is still required for the Steam session.

The APK and its SHA-256 are in the release assets.
