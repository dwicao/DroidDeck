# DroidDeck 0.6.5 — Faster game moves

Speeds up `Setup > Storage > Games > Move`, especially for games with tens of thousands of
small files such as Proton prefixes:

- The file copier reuses the sizes already measured for the free-space check instead of walking
  each game tree a second time before copying.
- Directory children are listed once per folder, files inside an already-created folder skip the
  redundant parent probe, and the transfer chunk grows from 4 MB to 8 MB — fewer syscalls per
  file on every copy and move in the app.

What still applies: stop the Steam session first, keep DroidDeck open and the storage plugged in
until the move finishes, and grant “All files access” when the drive asks for it. A failed copy
still rolls back and unregisters the destination.

### Install

- versionName `0.6.5`, versionCode `30`. It installs over the fork's 0.6.4 (versionCode `29`) and
  keeps app data.
- The APK is signed with the public AOSP test key. Android may show a Play Protect warning.
- Requires Android 9 or newer. A supported Adreno device is still required for the Steam session.

The APK and its SHA-256 are in the release assets.
