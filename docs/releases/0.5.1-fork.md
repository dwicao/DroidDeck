# DroidDeck 0.5.1 — Default storage

This release adds a default storage choice for new game downloads.

### What changed

- **Setup > Storage > Default storage** can now be set to **Internal storage**, **External storage**, or **Ask every time**.
- New installs from GOG, Epic, Amazon, Xbox, and itch use the selected target by default. The Epic Games Launcher also uses it for its own install directory.
- External storage uses the SD card or second library that DroidDeck already exposes. If it is not connected, the install falls back to the normal target prompt instead of writing somewhere unexpected.
- Games that are already installed are not moved. Steam libraries keep their own **Game storage** setting.

### Install

- versionName `0.5.1`, versionCode `22`. It installs over 0.5.0 (versionCode `21`) and keeps app data.
- The APK is signed with the public AOSP test key. Android may show a Play Protect warning; release-key signing was not available for this build.
- Requires Android 12 or newer. A 64-bit Adreno device is still required for the Steam session.

The APK and its SHA-256 are in the release assets.
