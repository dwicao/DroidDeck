# DroidDeck 1.2.1 — GPU/CPU temperatures in the performance HUD

Small follow-up to 1.2.0: the on-panel performance readout now shows the
sampled GPU and CPU temperatures next to the clocks
(`thermal none cpu 2227/3360 gpu 719 MHz gpu 67°C cpu 70°C`), so a settling
frame rate reads with its thermal reason on the panel instead of only in
`perf.csv`.

### Install

- versionName `1.2.1`, versionCode `43`. It installs over any previous fork
  release and keeps app data.
- The APK is signed with the public AOSP test key. Android may show a Play Protect warning.
- Requires Android 9 or newer. A supported Adreno device is still required for the Steam session.

The APK and its SHA-256 are in the release assets.
