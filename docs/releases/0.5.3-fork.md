# DroidDeck 0.5.3 — Upstream main merge

This release merges `Droid-Deck/DroidDeck:main` through `3c0633fe` (88 commits) into the fork and
keeps the fork's storage, pacing, GPU, and game-kit changes.

### Upstream changes

- Remote Play host support: PipeWire capture, hardware encoding, touch input, and game audio.
- SteamVR controller types, phone controls on glasses, and flat games as VR panels; Rokid Max and
  Air glasses support with 3DoF, SBS modes, 120 Hz, and brightness controls.
- A performance HUD frame-time graph, battery temperature, and opacity controls.
- GOG and Epic installs can choose a game language; GOG uses its official listing endpoint.
- DroidDeck's linux-nightly components with a Stable/Nightly switch, plus a Decky Loader update
  channel selector and a warning before installing a Decky plugin ZIP.
- Proot, DirectAudio, Xbox, Comet, and hand tracking ship as CI-built add-on packs.
- Desktop mode can be uninstalled safely, games can be removed from the Games page, and store tabs
  can be arranged and hidden.
- Controller fixes for Steam Controller BLE, Factorio's ARM64 input, Rewired games, virtual input
  devices, touch layouts, and the first player slot.
- File manager fixes for symlink-preserving copy/move, cancelling a paste, search-filtered
  selection, and slow folder listings.
- Android 9 and 10 in-app updates, Chromium browsers on the desktop, Turkish translations, and
  assorted FEX, Wine, cloud-save, and store sign-in fixes.

### Fork changes kept

- **Setup > Storage > Default storage** still chooses internal storage, external storage, any
  writable folder via **Choose folder…**, or asks every time. New store installs and the Epic Games
  Launcher use that choice; existing games and Steam libraries stay where they are.
- The fork's panel-based pacing, GPU clock pin and thermal guard, per-game launch log, game-kit
  export/import, and x86 Linux runtime handling remain in place.

### Install

- versionName `0.5.3`, versionCode `24`. It installs over 0.5.2 (versionCode `23`) and keeps app data.
- The APK is signed with the public AOSP test key. Android may show a Play Protect warning;
  release-key signing was not available for this build.
- Requires Android 9 or newer. A supported Adreno device is still required for the Steam session.

The APK and its SHA-256 are in the release assets.
