# DroidDeck 0.6.14 — Universal compat and stability

- **Safer Vulkan defaults.** `VKD3D_FEATURE_LEVEL` now defaults to `12_1` instead of `12_2`:
  vkd3d-proton disables mesh shaders on Adreno anyway, and advertising `12_2` crashes Unreal
  Engine 5 games while creating pipelines (RoboCop: Rogue City, #1410). A per-game override
  still wins.
- **Idle-friendly Steam home.** The floating capsule fan plays its float once on appearance
  and then holds still instead of recomposing every frame forever (~2,400 frames per 10 s
  idle, #1499). Less CPU/GPU burn while browsing means less heat before a session.
- **Working Browse buttons.** Backported upstream fixes so every Browse button on the ARM64
  Steam client (Add a Non-Steam Game, shortcut target, library folder) opens a file chooser
  (#1433), keeps spaces in the chosen path, and cancels cleanly when GTK 3 is missing.
- **Defaults audit.** Reviewed the other `GameEnvironment` graphics defaults for Adreno;
  only the feature level had issue evidence behind it, so nothing else changed.

### Install

- versionName `0.6.14`, versionCode `39`. It installs over the fork's 0.6.13 (versionCode `38`) and
  keeps app data.
- The APK is signed with the public AOSP test key. Android may show a Play Protect warning.
- Requires Android 9 or newer. A supported Adreno device is still required for the Steam session.

The APK and its SHA-256 are in the release assets.
