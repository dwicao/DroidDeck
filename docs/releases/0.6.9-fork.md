# DroidDeck 0.6.9 — Install into Steam, by name too

`Setup > Storage > Added games` now also offers **Install into Steam** when a folder is named
exactly like a Steam manifest's missing install folder, even if the folder carries no
steam_appid or emulator ini to identify it. The match is by folder name against manifests whose
files are absent; tapping it moves the folder into that library's `steamapps/common/<installDir>`
and Steam detects the game on its next start.

### Install

- versionName `0.6.9`, versionCode `34`. It installs over the fork's 0.6.8 (versionCode `33`) and
  keeps app data.
- The APK is signed with the public AOSP test key. Android may show a Play Protect warning.
- Requires Android 9 or newer. A supported Adreno device is still required for the Steam session.

The APK and its SHA-256 are in the release assets.
